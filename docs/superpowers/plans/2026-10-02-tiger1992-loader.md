# 1992 TIGER/Line Loader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load 1992 TIGER/Line county files into the existing `tiger` schema so the forward geocoder works against 1992-vintage data with no macro changes.

**Architecture:** A sibling module `src/loader_1992.cpp` reuses the modern loader's orchestration (download, scrape, progress ledger, `ANALYZE`) via a newly-extracted shared header, but ingests fixed-width ASCII with `read_csv` + `substr` instead of GDAL `ST_Read`. County zips are extracted with DuckDB's bundled miniz. Transformation SQL lives in a new embedded `src/sql/loader_1992_templates.sql.in`.

**Tech Stack:** C++11 (extension ABI baseline), DuckDB 1.5.3, DuckDB's bundled `duckdb_miniz`, `spatial` (for `ST_MakeLine`/`ST_Point`/`GEOMETRY`), sqllogictest.

**Spec:** [docs/superpowers/specs/2026-10-02-tiger1992-loader-design.md](../specs/2026-10-02-tiger1992-loader-design.md)

## Global Constraints

- **C++11 only** — no `inline constexpr std::string_view`, no structured bindings in public headers.
- **Branch:** `feature/1992tiger`.
- **Macros always live in the local `tiger` schema** and reference `tiger.<table>` unqualified. Templates use `@TIGER@` for the data location and `@FUNC@` for the macro location; these differ only when `target_db` is set.
- **Named parameter is `target_schema`, not `schema`.** Full set for the new functions: `source`, `target_db`, `target_schema`, `build_containment`, `parallel`, `temp_dir`, `parallel_workers`. **No `year`** — pinned to 1992.
- **Default source:** `https://www2.census.gov/geo/tiger/TIGER1992`.
- **Do not use GDAL's native TIGER driver.** It exists and works, but is deprecated upstream. See spec § On D-F.
- **Struct fields in macros use bracket notation** (`inp['zip']`), never dot.
- **Fixture `featnames` rows must populate all six precomputed columns**: `name_lower`, `fullname_norm`, `name_soundex`, `numeric_stem`, `name_first_5`, `fullname_first_5`.
- **Do not change rating weights or the "location ratings ≥ 100" invariant.**
- **Run the full suite after any SQL change**: `TIGER_TEST_EXTENSIONS=1 ./build/release/test/unittest "test/sql/*"`. Individual file runs miss regression interactions.
- **Commit messages**: short subject + 1–3 sentences of body. End with `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- **Build:** `make release` (~30s hot).

## Review Focus

Input classes the spec implies but which no task's primary tests would otherwise exercise. Each has a test assigned to the task owning the code.

1. **A county whose `.F54`/`.F55`/`.F56` is absent or zero-byte** — RT4/RT5/RT6 are optional per county. The load must succeed with zero extra rows rather than erroring. → Task 3 Step 3 (empty-file scan) and Task 4 Step 12 (end-to-end, county `34997`).
2. **ZIP codes with leading zeros** — `'07825'` must not become `'7825'`. This is the explicit reason GDAL was rejected, so it must be pinned. → Task 3 Step 3 and Task 4 Step 1.
3. **A record line shorter than its layout** (truncated final line, blank line) — must be skipped, not yield a row with garbage offsets. → Task 3 Step 3.
4. **An unknown state abbreviation** (e.g. `'ZZ'`) — must raise a clear error naming the abbreviation, not crash or silently load nothing. → Task 4 Step 1.
5. **`require_containment := 'block'` against 1992 data** — documented to return zero rows; must not error. → Task 5 Step 1.

- [ ] **Step 5: Write the implementation**

Create `src/zip_extract.cpp`:

```cpp
#include "us_geocoder_zip.hpp"

#include "duckdb/common/file_system.hpp"
#include "duckdb/main/extension/extension_loader.hpp"
#include "miniz.hpp"

#include <algorithm>
#include <cstring>

namespace duckdb {
namespace us_geocoder {

static std::string ToLowerAscii(const std::string &s) {
	std::string out = s;
	for (size_t i = 0; i < out.size(); ++i) {
		out[i] = static_cast<char>(::tolower(static_cast<unsigned char>(out[i])));
	}
	return out;
}

// Strip any directory component an archive entry may carry.
static std::string BaseName(const std::string &path) {
	auto pos = path.find_last_of("/\\");
	return pos == std::string::npos ? path : path.substr(pos + 1);
}

std::vector<ZipEntry> ExtractZipEntries(FileSystem &fs, const std::string &zip_path,
                                        const std::string &dest_dir,
                                        const std::vector<std::string> &wanted) {
	// Read the whole archive into memory. County zips are ~1 MB; the largest
	// 1992 state's OtherFiles.zip is a few MB. MINIZ_NO_STDIO is defined in
	// DuckDB's miniz build, so only the *_mem APIs exist anyway.
	if (!fs.FileExists(zip_path)) {
		throw IOException("us_geocoder_unzip: archive not found: %s", zip_path);
	}
	auto handle = fs.OpenFile(zip_path, FileFlags::FILE_FLAGS_READ);
	auto size = fs.GetFileSize(*handle);
	if (size <= 0) {
		throw IOException("us_geocoder_unzip: archive is empty: %s", zip_path);
	}
	std::vector<char> buffer(static_cast<size_t>(size));
	fs.Read(*handle, buffer.data(), size);
	handle.reset();

	mz_zip_archive zip;
	memset(&zip, 0, sizeof(zip));
	if (!mz_zip_reader_init_mem(&zip, buffer.data(), buffer.size(), 0)) {
		throw IOException("us_geocoder_unzip: not a readable zip archive: %s", zip_path);
	}

	std::vector<std::string> wanted_lower;
	for (size_t i = 0; i < wanted.size(); ++i) {
		wanted_lower.push_back(ToLowerAscii(wanted[i]));
	}

	fs.CreateDirectory(dest_dir);

	std::vector<ZipEntry> written;
	const mz_uint n = mz_zip_reader_get_num_files(&zip);
	for (mz_uint i = 0; i < n; ++i) {
		mz_zip_archive_file_stat stat;
		if (!mz_zip_reader_file_stat(&zip, i, &stat)) {
			continue;
		}
		if (mz_zip_reader_is_file_a_directory(&zip, i)) {
			continue;
		}
		const std::string base = BaseName(stat.m_filename);
		// Match case-insensitively ourselves rather than trusting
		// mz_zip_reader_locate_file's flag-dependent case behaviour.
		// 1992 archives store entries in uppercase.
		if (!wanted_lower.empty()) {
			const std::string base_lower = ToLowerAscii(base);
			if (std::find(wanted_lower.begin(), wanted_lower.end(), base_lower) == wanted_lower.end()) {
				continue;
			}
		}
		size_t out_size = 0;
		void *bytes = mz_zip_reader_extract_to_heap(&zip, i, &out_size, 0);
		if (!bytes) {
			mz_zip_reader_end(&zip);
			throw IOException("us_geocoder_unzip: failed to inflate entry %s from %s", base, zip_path);
		}
		const std::string out_path = fs.JoinPath(dest_dir, base);
		{
			auto out = fs.OpenFile(out_path, FileFlags::FILE_FLAGS_WRITE | FileFlags::FILE_FLAGS_FILE_CREATE_NEW);
			if (out_size > 0) {
				fs.Write(*out, bytes, static_cast<int64_t>(out_size));
			}
		}
		mz_free(bytes);
		ZipEntry e;
		e.name = base;
		e.bytes = static_cast<int64_t>(out_size);
		written.push_back(e);
	}
	mz_zip_reader_end(&zip);
	return written;
}

// ---------------------------------------------------------------------
// us_geocoder_unzip table function
// ---------------------------------------------------------------------

struct UnzipBindData : public FunctionData {
	std::string zip_path;
	std::string dest_dir;
	unique_ptr<FunctionData> Copy() const override {
		auto r = make_uniq<UnzipBindData>();
		r->zip_path = zip_path;
		r->dest_dir = dest_dir;
		return std::move(r);
	}
	bool Equals(const FunctionData &other) const override {
		auto &o = other.Cast<UnzipBindData>();
		return zip_path == o.zip_path && dest_dir == o.dest_dir;
	}
};

struct UnzipGlobalState : public GlobalTableFunctionState {
	std::vector<ZipEntry> rows;
	idx_t offset = 0;
	bool ran = false;
	static unique_ptr<GlobalTableFunctionState> Init(ClientContext &, TableFunctionInitInput &) {
		return make_uniq<UnzipGlobalState>();
	}
};

static unique_ptr<FunctionData> UnzipBind(ClientContext &, TableFunctionBindInput &input,
                                          vector<LogicalType> &return_types, vector<string> &names) {
	auto result = make_uniq<UnzipBindData>();
	result->zip_path = StringValue::Get(input.inputs[0]);
	result->dest_dir = StringValue::Get(input.inputs[1]);
	return_types.push_back(LogicalType::VARCHAR);
	names.emplace_back("entry");
	return_types.push_back(LogicalType::BIGINT);
	names.emplace_back("bytes");
	return std::move(result);
}

static void UnzipExecute(ClientContext &context, TableFunctionInput &data_p, DataChunk &output) {
	auto &bind = data_p.bind_data->Cast<UnzipBindData>();
	auto &gstate = data_p.global_state->Cast<UnzipGlobalState>();
	if (!gstate.ran) {
		auto &fs = FileSystem::GetFileSystem(context);
		gstate.rows = ExtractZipEntries(fs, bind.zip_path, bind.dest_dir, {});
		gstate.ran = true;
	}
	idx_t count = 0;
	while (gstate.offset < gstate.rows.size() && count < STANDARD_VECTOR_SIZE) {
		output.SetValue(0, count, Value(gstate.rows[gstate.offset].name));
		output.SetValue(1, count, Value::BIGINT(gstate.rows[gstate.offset].bytes));
		++gstate.offset;
		++count;
	}
	output.SetCardinality(count);
}

void RegisterZipFunctions(ExtensionLoader &loader) {
	TableFunction fn("us_geocoder_unzip", {LogicalType::VARCHAR, LogicalType::VARCHAR}, UnzipExecute, UnzipBind,
	                 UnzipGlobalState::Init);
	loader.RegisterFunction(fn);
}

} // namespace us_geocoder
} // namespace duckdb
```

```sql
-- Per-table INSERT templates for the 1992 TIGER/Line loader. Sections are
-- delimited by "-- @SECTION:name@" and parsed by ExtractSection().
-- Placeholders substituted per-call:
--   @TIGER@    → data location ("tiger", or "refdb.tiger" with target_db)
--   @FUNC@     → local macro location (always "tiger")
--   @STATEFP@  → 2-digit state FIPS
--   @COUNTYFP@ → 3-digit county FIPS
--   @STUSPS@   → 2-letter state abbrev (from state_lookup, not in the files)
--   @F51@ … @F5I@, @NAM@ → fully-resolved paths to the extracted files
--
-- Record layouts are documented in
-- docs/superpowers/specs/2026-10-02-tiger1992-loader-design.md § Record layouts.
-- Offsets are exact: record widths were verified byte-for-byte against the
-- 1992 Census documentation.
--
-- delim='\x1f' is a byte that cannot occur in printable-ASCII TIGER content,
-- so read_csv never splits a record; it just hands back whole lines.

-- @SECTION:county_edges@
INSERT INTO @TIGER@.edges
    (statefp, countyfp, tlid, tfidl, tfidr, tnidf, tnidt, mtfcc, fullname, the_geom, zipl, zipr)
WITH rt1 AS (
    SELECT substr(line,6,10)::BIGINT                   AS tlid,
           nullif(trim(substr(line,18,2)),'')          AS fedirp,
           nullif(trim(substr(line,20,30)),'')         AS fename,
           nullif(trim(substr(line,50,4)),'')          AS fetype,
           nullif(trim(substr(line,54,2)),'')          AS fedirs,
           trim(substr(line,56,3))                     AS cfcc,
           nullif(trim(substr(line,107,5)),'')         AS zipl,
           nullif(trim(substr(line,112,5)),'')         AS zipr,
           trim(substr(line,191,10))::BIGINT           AS frlong,
           trim(substr(line,201,9))::BIGINT            AS frlat,
           trim(substr(line,210,10))::BIGINT           AS tolong,
           trim(substr(line,220,9))::BIGINT            AS tolat
    FROM (SELECT rtrim(line, chr(13)) AS line
          FROM read_csv('@F51@', columns={'line':'VARCHAR'}, delim='\x1f',
                        header=false, quote='', escape=''))
    WHERE length(line) >= 228
),
rt2 AS (
    SELECT substr(line,6,10)::BIGINT AS tlid,
           substr(line,16,3)::INT    AS rtsq,
           g.i                       AS slot,
           trim(substr(line, 19 + (g.i-1)*19, 10))::BIGINT AS lon,
           trim(substr(line, 29 + (g.i-1)*19,  9))::BIGINT AS lat
    FROM (SELECT rtrim(line, chr(13)) AS line
          FROM read_csv('@F52@', columns={'line':'VARCHAR'}, delim='\x1f',
                        header=false, quote='', escape='')) s,
         generate_series(1,10) g(i)
    WHERE length(s.line) >= 208
      AND trim(substr(s.line, 19 + (g.i-1)*19, 10))::BIGINT <> 0
),
rti AS (
    SELECT substr(line,6,10)::BIGINT AS tlid,
           CASE WHEN trim(substr(line,22,5)) <> '' AND trim(substr(line,27,10)) <> ''
                THEN trim(substr(line,22,5))::BIGINT * 10000000000
                   + trim(substr(line,27,10))::BIGINT END AS tfidl,
           CASE WHEN trim(substr(line,37,5)) <> '' AND trim(substr(line,42,10)) <> ''
                THEN trim(substr(line,37,5))::BIGINT * 10000000000
                   + trim(substr(line,42,10))::BIGINT END AS tfidr
    FROM (SELECT rtrim(line, chr(13)) AS line
          FROM read_csv('@F5I@', columns={'line':'VARCHAR'}, delim='\x1f',
                        header=false, quote='', escape=''))
    WHERE length(line) >= 51
),
pts AS (
    SELECT tlid, 0       AS ord, 0    AS slot, frlong AS lon, frlat AS lat FROM rt1
    UNION ALL
    SELECT tlid, rtsq,          slot,        lon,          lat           FROM rt2
    UNION ALL
    SELECT tlid, 1000000 AS ord, 0    AS slot, tolong,      tolat         FROM rt1
),
geo AS (
    SELECT tlid, ST_MakeLine(list(ST_Point(lon/1e6, lat/1e6) ORDER BY ord, slot)) AS the_geom
    FROM pts GROUP BY tlid
)
SELECT '@STATEFP@', '@COUNTYFP@', r.tlid, i.tfidl, i.tfidr,
       -- Node identity == coordinate identity. Derived from the raw
       -- microdegree integers so it is exact, collision-free and stable
       -- across county files (geocode_intersection joins across them).
       (r.frlong + 180000000) * 1000000000 + (r.frlat + 90000000),
       (r.tolong + 180000000) * 1000000000 + (r.tolat + 90000000),
       CASE WHEN r.cfcc LIKE 'A1%' THEN 'S1100'
            WHEN r.cfcc LIKE 'A2%' THEN 'S1200'
            WHEN r.cfcc LIKE 'A3%' OR r.cfcc LIKE 'A4%' THEN 'S1400'
            WHEN r.cfcc LIKE 'A5%' OR r.cfcc LIKE 'A6%' OR r.cfcc LIKE 'A7%' THEN 'S1500'
            WHEN r.cfcc LIKE 'A%'  THEN 'S1400'
            ELSE 'X' || r.cfcc END,
       nullif(trim(concat_ws(' ', r.fedirp, r.fename, r.fetype, r.fedirs)), ''),
       g.the_geom, r.zipl, r.zipr
FROM rt1 r
JOIN geo g USING (tlid)
LEFT JOIN rti i USING (tlid);

-- @SECTION:county_faces@
-- the_geom stays NULL: 1992 ships no polygon geometry and forward
-- geocoding joins faces only on tfid for placefp/cousubfp/tract/block.
INSERT INTO @TIGER@.faces
    (statefp, countyfp, tfid, placefp, cousubfp, tractce20, blockce20, blkgrpce20, the_geom)
SELECT '@STATEFP@', '@COUNTYFP@',

           nullif(trim(substr(line,50,4)),'')  AS fetype,

           trim(substr(line,56,3))             AS cfcc

    FROM rt4 x

    JOIN rt1 r ON r.tlid = x.tlid

            WHEN cfcc LIKE 'A3%' OR cfcc LIKE 'A4%' THEN 'S1400'
            WHEN cfcc LIKE 'A5%' OR cfcc LIKE 'A6%' OR cfcc LIKE 'A7%' THEN 'S1500'
```

```cpp
// County FIPS list for a state. Remote: scrape <source>/<ss>/ for
// <ssccc>.zip. Local: list <source>/<ss>/ for either <ssccc>.zip files or
// <ssccc>/ directories, so both local layouts work.
static std::vector<std::string> ListCounties1992(ClientContext &context, FileSystem &fs,
                                                 const Loader1992BindData &bind, const std::string &fips) {
	std::vector<std::string> out;
	const bool remote = bind.source.rfind("http://", 0) == 0 || bind.source.rfind("https://", 0) == 0;
	if (remote) {
		std::string base = bind.source;
		if (!base.empty() && base.back() == '/') {
			base.pop_back();
		}
		ParallelDownloadOptions opts;
		opts.workers = 1; // one GET for the directory index
		opts.max_attempts = 3;
		opts.log_prefix = fips;
		const std::string pattern_str = "^" + fips + "[0-9]{3}\\.zip$";
		std::regex pat(pattern_str);
		auto names = ScrapeCensusIndex(context, base + "/" + fips + "/", pat, opts);
		if (names.empty()) {
			throw IOException("us_geocoder 1992: index %s/%s/ yielded no county zips (pattern %s)", base, fips,
			                  pattern_str);
		}
		for (size_t i = 0; i < names.size(); ++i) {
			// "<ssccc>.zip" -> "ccc"
			out.push_back(names[i].substr(2, 3));
		}
	} else {
		const std::string state_dir = fs.JoinPath(bind.source, fips);
		if (!fs.DirectoryExists(state_dir)) {
			throw IOException("us_geocoder 1992: no such directory: %s", state_dir);
		}
		fs.ListFiles(state_dir, [&](const string &name, bool is_dir) {
			if (is_dir) {
				if (name.size() == 5 && name.compare(0, 2, fips) == 0) {
					out.push_back(name.substr(2, 3));
				}
			} else if (name.size() == 9 && name.compare(0, 2, fips) == 0 &&
			           name.compare(5, 4, ".zip") == 0) {
				out.push_back(name.substr(2, 3));
			}
		});
		if (out.empty()) {
			throw IOException("us_geocoder 1992: no county zips or county directories under %s", state_dir);
		}
	}
	std::sort(out.begin(), out.end());
	out.erase(std::unique(out.begin(), out.end()), out.end());
	return out;
}
```

```cpp
				out.push_back({std::string(t.section) + ":" + cfp + ":skipped", 0});
				continue;
			}
			if (dir.empty()) {
				dir = ResolveCountyDir(context, fs, bind, fips, cfp, work_dir);
			}
			auto sql = RenderTemplate(
			    ExtractSection(tmpl, t.section),
			    {{"@TIGER@", data_loc},
			     {"@FUNC@", func_loc},
			     {"@STATEFP@", fips},
			     {"@COUNTYFP@", cfp},
			     {"@F51@", fs.JoinPath(dir, "TGR" + ssccc + ".F51")},
			     {"@F52@", PathOrEmpty(fs, dir, "TGR" + ssccc + ".F52", work_dir)},
			     {"@F54@", PathOrEmpty(fs, dir, "TGR" + ssccc + ".F54", work_dir)},
			     {"@F55@", PathOrEmpty(fs, dir, "TGR" + ssccc + ".F55", work_dir)},
			     {"@F56@", PathOrEmpty(fs, dir, "TGR" + ssccc + ".F56", work_dir)},
			     {"@F5A@", fs.JoinPath(dir, "TGR" + ssccc + ".F5A")},
			     {"@F5I@", fs.JoinPath(dir, "TGR" + ssccc + ".F5I")}});
			int64_t rows = ExecuteInsert(conn, sql, std::string(t.section) + ":" + cfp);
			out.push_back({std::string(t.section) + ":" + cfp, rows});
			MarkProgressDone(conn, data_loc, key);
		}
	}
}
```
